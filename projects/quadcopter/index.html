ESP32 Quadcopter

Embedded flight control · Jul - Aug 2026

What it is

I built an ESP32 quadcopter on an F450 frame and made a controller around an F310 USB gamepad. The aircraft uses esp-fc firmware for flight stabilization.

How it works

An ESP32-S3 reads the gamepad and sends throttle, roll, pitch, yaw and arm/disarm commands over ESP-NOW. My transmitter code maps USB input reports, adjusts stick response, limits throttle changes and handles arming controls. It uses the EspUsbHost and EspNowRcLink libraries.

I assembled the aircraft and connected the MPU-6500 IMU, BMP280 barometer and QMC5883L magnetometer over I2C. Flight stabilization, sensor fusion and motor mixing are provided by esp-fc, rather than a flight controller written from scratch for this flying configuration.

Results

The quadcopter took off, hovered and flew under manual gamepad control. I confirmed receiver-monitor responses for the control channels and checked motor mapping, spin direction and ESC calibration before flight.

Disconnecting the wireless control link stopped all four motors within approximately 500 ms. This was an observed test result, not a measured worst-case bound. An altitude-hold switch exists in the transmitter code, but altitude hold has not been established as a confirmed flight result.

Source and demonstrations

The repository contains the F310 transmitter and ESC calibration utility. Exact working dependency revisions and flight demonstrations remain to be added.

Tools: C++, Arduino, ESP32, ESP-NOW, I2C
