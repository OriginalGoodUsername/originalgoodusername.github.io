Project notes

I designed and assembled a 3D-printed arm with six servos, two at the shoulder, and a NEMA-17 stepper base. The Python controller takes typed 3D target coordinates and uses inverse kinematics to search gripper pitch for a solution within joint limits. I connected Python to Arduino over serial, with a PCA9685 driving the servos and an A4988 driving the stepper.

The shoulder servos are mirrored, and the channel mapping has to account for reversed physical wiring. I used two calibration poses to map joint angles to servo commands, with linear interpolation between those poses.

The pictured Python/Matplotlib interface has reach, height and base-yaw sliders alongside a 3D arm view. Reach and base yaw set the target's X/Y coordinates, and height sets Z. The target marker turns green or red to show whether the solver reports a solution. The tool opens in simulation mode and includes an optional serial-control mode.
