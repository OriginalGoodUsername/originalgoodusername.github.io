6-DOF Robotic Arm with Inverse Kinematics

Kinematics and motor control · Jan - Mar 2026

What it is

I set out to connect typed 3D target positions to a physical robotic arm, with a live model showing the arm’s movement. The solver needed to work within the arm’s joint limits.

How it works

My analytical inverse-kinematics solver uses the law of cosines and searches gripper pitch to find solutions for typed 3D targets within joint limits.

A handshaked serial link connects Python to an Arduino. The 3D-printed arm uses six servos through a PCA9685 and a NEMA 17 stepper through an A4988. A live Matplotlib simulator with slider controls moves the on-screen model and real arm together.

Results

The physical arm and simulator move together using slider controls. The viewer uses a 40 ms update timer, separate from input events; its nominal 25 Hz setting is not a rendering benchmark.

The repository contains the control and calibration scripts. The kinematics module and matching Arduino firmware are missing from this local copy, so the release is not yet a complete runnable project.

Tools: Python, NumPy, Matplotlib, Arduino, pySerial
