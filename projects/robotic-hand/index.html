Project notes

I built a robotic hand that copies my hand movements from a webcam without a glove. It has five finger servos and one wrist servo. I implemented the controller in Python and Arduino, connecting hand tracking to the physical hand's movement.

My Python controller uses OpenCV and MediaPipe to process webcam hand landmarks. It maps the landmark geometry to finger curl and thumb position, then converts these into six calibrated servo angles. Commands go over serial to an Arduino, which drives the servos through a PCA9685. I used calibrated open and closed angles, with a separate range for the thumb.

The command pipeline uses exponential moving-average smoothing and limits how far servo commands can change per frame. When webcam tracking disappears, the Python controller briefly holds the last tracked pose before returning toward an open hand. Manual control and a servo-test utility let me adjust the calibrated angles.
