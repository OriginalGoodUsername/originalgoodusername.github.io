Hybrid Quadruped Robot

Robot build and platform port · Personal project

What it is

I designed and built a robot with two ways to move: walking on four legs and driving on four wheels. An Arduino Nano ESP32 controls twelve leg servos through a PCA9685 and four DC motors through two TB6612 drivers.

How it works

I adapted legacy AVR gait code to the ESP32, replacing its timer-interrupt servo loop with a FreeRTOS task. The project combines inverse-kinematics walking gaits with wheeled drive and an ESP-NOW gamepad link.

The hardware work included power distribution and decoupling. I wrote bring-up tools to scan the I2C bus, test individual servos and motors, centre the servos and record calibration pulse values.

Source and demonstrations

The repository contains four hardware-test and calibration tools. The integrated walking-and-wheel controller is on another computer and is not part of this release. Older local sketches are incomplete variants.

The legacy gait code carries SunFounder, Regis Hsu and Anuchit attribution. My mechanical design and integration work do not imply authorship of those original gait algorithms. Source credits are retained with the available code.

Tools: Arduino Nano ESP32, FreeRTOS, PCA9685, TB6612, ESP-NOW
